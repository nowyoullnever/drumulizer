# Ratchet

Ratchet Count expands one Pattern Event into one to four subtriggers inside the current Step. Count 1 is ordinary playback.

## Timing

Subtriggers are evenly spaced inside one Step. Ratchet does not create additional editable Events and does not change the grid.

## Decay

Ratchet Decay reduces gain from the first to final subtrigger. Decay 0 keeps equal gain. Decay 100 makes later subtriggers quieter.

## Interactions

Probability is evaluated once before Ratchet expansion. Granular mode may create grains inside each Ratchet trigger window. Expansion remains bounded.
