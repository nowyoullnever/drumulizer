# Slice Library

The Slice Library replaces the disabled Pattern Workspace placeholder in v0.5.0. It is a functional inspection and curation surface for committed slices.

## Capabilities

- Run committed slice analysis.
- View analysis lifecycle state and progress.
- Filter by role, included, excluded, or all.
- Sort by index, role, confidence, duration, or RMS.
- Inspect selected-slice role score context and feature details.
- Override a selected slice role.
- Exclude/include slices.
- Reset selected annotations, reset all annotations, or include all.
- View role distribution summary.

## Relationship To Future Pattern Work

The library prepares role-aware slice metadata for later generation work, but v0.5.0 does not include a sequencer, pattern generation, export, save/load, MIDI, or user-editable DSP weights.
