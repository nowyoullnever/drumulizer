# Versioning

Drumulizer uses semantic versioning during staged product development.

- v0.1.0: Project foundation and visual system
- v0.2.0: Audio import, waveform display, and playback
- v0.3.0: Manual slice editor and slice audition
- v0.4.0: Offline onset detection
- v0.5.0: Slice analysis and role scoring
- v0.6.0: HPSS and derived slices
- v0.7.0: Sequencer and scheduling engine
- v0.8.0: IDM pattern and granular engine
- v0.9.0: Save, export, and Windows packaging
- v1.0.0: First stable release

Patch versions are reserved for fixes within an already shipped feature area, for example:

- v0.4.1: Duplicate onset marker fix
- v0.7.1: Scheduler drift fix
